# 숲 식물 찾기 (Tree_app)

숲에서 만난 나무와 들꽃의 이름을 **질문에 하나씩 답하며** 알아내는 가장 기본적인 식물 동정 앱입니다.

```
나무인가 풀인가 → 침엽수인가 활엽수인가 → (침엽) 잎이 몇 개씩 묶여 있나
                                         → (활엽) 홑잎인가 겹잎인가 → 잎 모양(둥근형·타원형…)
                                           → 톱니(거치)가 있나 → 교목·관목·덩굴 → 잎차례
                                           → 꽃 색 → 꽃잎 수·모양 → 개화기 → 열매 → 수피 → 가시
```

## 특징
- **단계별 질문**: 남은 후보를 실제로 가를 수 있는 질문만 차례로 묻습니다. 이미 답이 정해진 질문은 자동으로 건너뜁니다.
- **그림 선택지**: 잎 모양·톱니·겹잎·잎차례·꽃잎 모양 등을 그림으로 보여 줘 처음 보는 사람도 고를 수 있습니다.
- **모르면 건너뛰기**: 꽃이 없는 계절 등 확인할 수 없는 특징은 건너뛸 수 있습니다.
- **실수에 강함**: 답이 하나 틀려도 "가장 비슷한 후보"를 보여 주고, 위쪽 답 칩을 눌러 지우면 바로 다시 계산됩니다.
- **다른 특징부터**: "다른 특징으로 먼저 찾기"로 눈에 띄는 특징(예: 꽃 색)부터 답할 수 있습니다.
- **결과 화면**: 핵심 식별 포인트, 헷갈리는 식물과의 차이, 독성 주의, 형질 표.
- **도감**: 전체 식물을 이름·학명·과로 검색.

### 📘 학습 기능 (해설가·일반인의 동정 공부용)
- **학습 모드**: 질문 화면의 "📘 학습 모드"를 켜면 선택지별 후보 수를 숨겨 숫자가 아니라 **관찰로** 고르게 합니다.
  답할 때마다 "몇 종이 제외됐고, 각각 어떤 특징이 달라서인지"(예: 바늘잎 — 소나무, 잣나무…)를 보여 줍니다.
- **왜 이걸 보나요?**: 질문마다 그 형질이 어떤 식물 무리를 가르는지, 동정에서 왜 중요한지 설명합니다.
- **실물과 비교해 확인하기**: 결과가 나오면 핵심 특징(과 건너뛴 특징)을 실제 식물에서 하나씩 "맞아요/아니에요/못 봄"으로 확인합니다.
  맞지 않는 특징이 있으면 "어느 답을 잘못 봤을 수 있는지, 그 답을 다르게 봤다면 어떤 식물인지"를 짚어 줍니다.
- 후보가 2~4종 남으면 핵심 특징과 구별법을 나란히 비교합니다.
- **오프라인 지원(PWA)**: 한 번 열어 두면 숲처럼 인터넷이 안 되는 곳에서도 동작합니다. 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

현재 수록: 우리나라 숲에서 흔한 나무 50여 종 + 들꽃 30여 종 (총 85종).

## 실행
빌드 과정이 없는 순수 HTML/JS 앱입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages(설정 → Pages → 브랜치 선택)로 올리면 휴대폰에서 바로 쓸 수 있습니다.

## 구조
| 파일 | 내용 |
|---|---|
| `js/data.js` | 질문(형질)과 식물 데이터 — **식물 추가는 여기만 고치면 됩니다** |
| `js/app.js` | 동정 엔진과 화면 |
| `js/icons.js` | 선택지 그림(SVG)을 코드로 그림 |
| `css/style.css` | 스타일 (다크 모드 지원) |
| `sw.js`, `manifest.webmanifest` | 오프라인·홈 화면 설치 |
| `tests/check.js` | 데이터 검증 + 모든 식물이 찾아지는지 시뮬레이션 (`node tests/check.js`) |

## 식물 추가하기
`js/data.js`의 `SPECIES` 배열에 다음처럼 추가합니다. 형질 값은 `QUESTIONS`의 선택지 값(`v`)을 쓰고,
사람마다 다르게 볼 수 있는 특징은 배열로 여러 값을 넣으면 됩니다. 모르는 형질은 비워 두면 그 질문에서 항상 통과합니다.

```js
{
  id: 'acer-pseudosieboldianum', name: '당단풍나무', sci: 'Acer pseudosieboldianum', family: '무환자나무과',
  t: { type: 'tree', leaf: 'broad', habit: 'tree', evergreen: 'decid', compound: 'simple', arrange: 'opp',
       shape: 'lobed', margin: 'double', fcolor: 'red', fform: ['5', 'cluster'], season: 'latespring', fruit: 'samara' },
  desc: '설명', keys: ['핵심 특징 1', '핵심 특징 2'], similar: '헷갈리는 종', warn: '(선택) 주의 사항',
}
```
추가한 뒤 `node tests/check.js`로 값이 올바른지 확인하세요.
